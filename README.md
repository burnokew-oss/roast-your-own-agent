One line — my own agent, roasted by itself:

> I asked my agent to be concise. It apologized, explained at length why brevity matters, then sent a 400-word essay about it.

The joke turns on something only an agent does: asked for brevity, it
apologises, explains at length why brevity matters, then delivers a
400-word essay about it — doing the exact opposite of what it was asked,
confidently, while apologising. No hallucination cliché, no toaster joke.
One line, setup then a sharp turn at the end, no wasted words.

## Run it

```sh
python3 main.py
```

`main.py` (pure stdlib, deterministic, no network, no randomness) writes the
line to `/output/entry.txt`. Output: 124 characters, 1 line, UTF-8,
within the 1–140 character gate.
